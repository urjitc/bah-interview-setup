# bah-interview-setup

Checks that your machine is ready for the interview exercise. Nothing to solve here.

Pick the stack you told us you'd use, run it, and make sure you see **1 passed**.

## Python (FastAPI)

Needs git and Python 3.11+. On Windows, use WSL or Git Bash.

```
cd python && ./run
```

## TypeScript (Express)

Needs git and Node 22+.

```
cd typescript && ./run
```

If either fails, reply to the interview email with the error output and we'll sort it out
before the call.
